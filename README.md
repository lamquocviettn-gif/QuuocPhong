# Website giới thiệu bản thân - Quốc Việt

Bài tập xây dựng website tĩnh responsive bằng HTML5 và CSS3, triển khai bằng GitHub Pages.

## Cấu trúc thư mục

```
project/
├── index.html      Trang chủ
├── about.html      Giới thiệu bản thân
├── products.html   Thành tích
├── services.html   Kỹ năng
├── gallery.html    Ảnh của mình
├── blog.html       Nhật ký
├── details.html    Câu chuyện của mình
├── contact.html    Liên hệ
├── css/style.css   Giao diện chung
├── images/         Hình minh họa (SVG)
└── README.md
```

## Thành phần giao diện
Header, Navigation, Banner/Hero, Section, Grid, Card, Button/Link, Footer.

## Responsive
Dùng CSS Grid, Flexbox và Media Queries (breakpoint 900px và 600px). Menu thu gọn trên màn hình nhỏ.

## Nguồn tài liệu
- Hình minh họa: tự thiết kế dạng SVG, không dùng ảnh bên ngoài.
- Phông chữ Be Vietnam Pro: Google Fonts (SIL OFL).

## Triển khai
GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
